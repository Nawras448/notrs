# notes_rs

تطبيق ملاحظات طرفي (TUI) خفيف وسريع مكتوب بلغة Rust.

## الميزات

- إنشاء وتحرير وحذف الملاحظات
- بحث مباشر أثناء الكتابة
- تنسيق Markdown حي أثناء الكتابة: عناوين `#`، قوائم نقطية ومرقمة، خانة اختيار، جداول، فواصل واقتباسات
- دعم كامل للعربية والكتابة من اليمين إلى اليسار (كشف تلقائي لاتجاه كل فقرة، وتبديل موضع المؤشر وعكس خريطة النقر)
- إعادة ترقيم تلقائية للقوائم المرقمة
- فرز الملاحظات (آخر تعديل، الأقدم، العنوان)
- واجهة TUI بألوان مخصصة
- تخزين محلي بـ JSON

## المتطلبات

- [Rust](https://www.rust-lang.org/tools/install) (إصدار 2021 أو أحدث)

## التنزيل والتشغيل

```bash
git clone https://github.com/yourusername/notes_rs.git
cd notes_rs
cargo run --release
```

أو للبناء فقط:

```bash
cargo build --release
./target/release/notes_rs
```

## الاستخدام

| المفتاح | الوظيفة |
|---|---|
| `n` | ملاحظة جديدة |
| `Enter` | فتح ملاحظة للتعديل |
| `Ctrl+S` | حفظ الملاحظة |
| `Ctrl+S` | الإعدادات (من شاشة القائمة) |
| `Tab` | التبديل بين العنوان والمحتوى |
| `Shift+Tab` | إلغاء إزاحة القائمة / الخلية السابقة في الجدول |
| `/` | بحث (يكتب أي حرف لبدء البحث) |
| `Esc` | إلغاء / مسح البحث |
| `d` | حذف الملاحظة |
| `j` / `k` أو `↑` / `↓` | التنقل بين الملاحظات |
| `g` | الذهاب إلى أول ملاحظة |
| `G` | الذهاب إلى آخر ملاحظة |
| `Ctrl+R` | فرز الملاحظات (تغيير الترتيب) |
| `q` أو `Ctrl+C` | خروج |

### اختصارات المحرر

| المفتاح | الوظيفة |
|---|---|
| `Ctrl+1` إلى `Ctrl+6` | تحويل السطر إلى عنوان (المستوى المقابل) |
| `Ctrl+0` | إزالة العنوان |
| `Ctrl+U` | قائمة نقطية / تبديل خانة الاختيار |
| `Ctrl+O` | قائمة مرقمة |
| `Ctrl+T` | إدراج قالب جدول 2×2 |
| `Tab` | إزاحة القائمة / الانتقال للخلية التالية في الجدول |
| `Shift+Tab` | إلغاء الإزاحة / الخلية السابقة |
| `Alt+↑` / `Alt+↓` | نقل السطر الحالي |
| `Enter` | استمرار القائمة تلقائيًا مع إعادة الترقيم (Enter على عنصر فارغ ينهيها) |
| `Ctrl+D` | حذف الملاحظة |
| النقر بالماوس | وضع المؤشر في الموضع البصري الصحيح (حتى مع RTL والجداول) |

## التخزين

- **الافتراضي**: `notes.json` في مجلد التشغيل الحالي.
- **تغيير الموقع**: افتح صفحة الإعدادات (`Ctrl+S` من شاشة القائمة)، اكتب المسار المطلوب واضغط `Enter`/`Ctrl+S`. يُحفظ الإعداد في `~/.config/notes_rs/config.json` ويبقى بين الجلسات، فيعمل البرنامج من أي مجلد بنفس الملاحظات.
- **مجلد بدل ملف**: إذا أدخلت مجلدًا (مثل `~/Documents`) يُضاف `notes.json` تلقائيًا بداخله. المسارات المنتهية بـ `.json` تُستخدم كما هي.
- **الترحيل التلقائي**: عند تغيير الموقع لأول مرة، تُنسخ الملاحظات من الموقع القديم إلى الجديد تلقائيًا (لا تُفقد البيانات).
- **فراغ حقل المسار** = العودة للسلوك الافتراضي.
- يدعم `~` (يوسّعه إلى مجلد المنزل)، ويعرض خطأً إن كان المسار نسبيًا أو غير قابل للكتابة، ورسالة نجاح بعد الحفظ.

