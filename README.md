# notes_rs

تطبيق ملاحظات طرفي (TUI) خفيف وسريع مكتوب بلغة Rust.

## الميزات

- إنشاء وتحرير وحذف الملاحظات
- بحث مباشر أثناء الكتابة
- واجهة TUI بألوان مخصصة
- تخزين محلي بـ JSON

## المتطلبات

- [Rust](https://www.rust-lang.org/tools/install) (إصدار 2021 أو أحدث)

## التنزيل والتشغيل

```bash
git clone https://github.com/yourusername/notes_rs.git
cd notes_rs
cargo run --release
```

أو للبناء فقط:

```bash
cargo build --release
./target/release/notes_rs
```

## الاستخدام

| المفتاح | الوظيفة |
|---|---|
| `n` | ملاحظة جديدة |
| `Enter` | فتح ملاحظة للتعديل |
| `Ctrl+S` | حفظ الملاحظة |
| `Tab` | التبديل بين العنوان والمحتوى |
| `/` | بحث (يكتب أي حرف لبدء البحث) |
| `Esc` | إلغاء / مسح البحث |
| `d` | حذف الملاحظة |
| `j` / `k` أو `↑` / `↓` | التنقل بين الملاحظات |
| `g` | الذهاب إلى أول ملاحظة |
| `G` | الذهاب إلى آخر ملاحظة |
| `q` أو `Ctrl+C` | خروج |

## الأنظمة المدعومة

- **Linux** (مُختبر)
- **macOS**
- **Windows**

## هيكل المشروع

```
notes_rs/
├── src/
│   ├── main.rs      # نقطة الدخول ومعالجة الأحداث
│   ├── app.rs       # منطق التطبيق
│   ├── storage.rs   # التعامل مع التخزين (JSON)
│   └── ui.rs        # واجهة المستخدم الرسومية
├── notes.json       # ملف تخزين الملاحظات
└── Cargo.toml       # إعدادات المشروع والاعتماديات
```
